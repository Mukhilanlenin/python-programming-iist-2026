# Combined files

Two deliverables that put the whole course into one notebook and one slide deck, in the order of the course schedule (Day 1 to Day 10).

## Python_Programming_Complete_Notebook.ipynb

- One notebook with a section per day and session, using the same headings as the schedule. Day sections are level-one headings, sessions are level-two headings, and each source notebook sits beneath its session.
- It contains every notebook in the course (about 1,030 cells). Student versions come first. Instructor solutions are labelled "instructor solutions" or "solutions".
- Saved outputs are cleared, so run each section yourself.
- The first cell is a table of contents.
- It reads data from `../datasets/`, so keep it in this folder next to `datasets/`.
- Do not use "Run All" for the whole file. Some cells wait for keyboard input, and the exercises contain blanks to fill in. Run one session at a time.
- Known issues in the original course notebooks are listed in the main README. They are unchanged here.

## Python_Programming_Complete_Slides.pptx

- 647 slides: a title slide, contents, a divider slide for every day, a divider slide for every session, and all 614 slide pages from the course decks, in schedule order.
- Slides that came from PDF decks are placed as pictures, so their text cannot be edited or searched. The originals are in `individual/`, with the editable PowerPoint files.
- Each slide has speaker notes that give the source file and the original page number.
- The Pandas deck is split across Day 7 (slides 1 to 21) and Day 8 (slides 22 to 77), matching the schedule.
- Days 1 (inauguration), 5 and 10 have divider slides only.
